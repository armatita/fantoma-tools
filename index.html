SFX Forge

Install a tool

Each tool installs separately, so you get one icon per tool rather than a folder of bookmarks. Open the tool first, then:

  1. Android (Chrome): menu ⋮ → Add to Home screen → Install.
  2. Windows (Chrome / Edge): the install icon at the right of the address bar, or menu → Cast, save and share → Install page as app.

Installed tools open in their own window with no browser chrome, keep working with no signal, and appear in the app drawer or Start menu like anything else.

About your saved work

Each tool saves into this browser on this device. Phone and computer keep entirely separate copies — there is no sync, by design, because syncing would mean handing an account token to a web page.

To move work between devices, or to keep a real backup, use Export backup at the bottom of any tool and Import backup on the other one. Clearing site data erases everything a tool has saved, so export anything you would be sad to lose.
