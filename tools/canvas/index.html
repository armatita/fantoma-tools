Objects come from Aseprite. The route that keeps colours exact:

  1. Make a palette in the Palettes tab, Export .gpl, and in Aseprite load it with ≡ (above the palette) → Load Palette…
  2. Draw, and tag each animation (Frame → Tags). Each tag becomes a state; a file with no tags becomes one state named after the file.
  3. File → Export Sprite Sheet: on Output, tick JSON Data (Hash or Array both work) and, under Meta, Tags. Leave Trim off and choose any layout except Packed.
  4. Import Aseprite… here, and select the .png and the .json together.

Colours must match a palette exactly; if some do not, the import says which and offers to add them — it never guesses a nearest colour.

Palettes

No palettes yet

A palette is an ordered list of colours. The order matters: a sprite stores positions in the palette, so index 2 must mean the same thing in every palette you might swap in.

Create one with + New, or import a .gpl, .hex or .pal file — Aseprite and Lospec both export them.

Each colour is shown as the panel will show it: cut to RGB565 the way the export does, then expanded back the way the panel driver does. Drag to reorder; the number is the index a sprite stores.
