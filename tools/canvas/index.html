The camera is what the screen shows, in pixels — 64 × 64 for Fantoma, but every project sets its own. The scene is the world the camera moves over; it is never smaller than the camera.

Placing objects in the scene arrives in phase 4.

Objects arrive in phase 2

A tree of objects → states → frames, filled by importing an Aseprite sprite sheet and its JSON: tags become states, and frames are read from the file rather than guessed from the sheet's size.

  • One cell size, one palette and one bit depth per object.
  • One duration per state, as the engine stores it.
  • Any pixel not in the object's palette reported, with where it is.
  • An animated preview on the engine's 16 ms tick, in panel colours.
  • The byte budget, live.

Start with a palette: export it as .gpl and load it into Aseprite, and the art drawn there will match it exactly.

Palettes

No palettes yet

A palette is an ordered list of colours. The order matters: a sprite stores positions in the palette, so index 2 must mean the same thing in every palette you might swap in.

Create one with + New, or import a .gpl, .hex or .pal file — Aseprite and Lospec both export them.

Each colour is shown as the panel will show it: cut to RGB565 the way the export does, then expanded back the way the panel driver does. Drag to reorder; the number is the index a sprite stores.
